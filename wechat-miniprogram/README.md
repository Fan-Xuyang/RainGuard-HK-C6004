# RainGuard 香港微信小程序

原生 WXML / WXSS / JavaScript 工程，复用项目的 Node 服务端。包含总览、观测、助手、现场工作台、知识库、设置六个页面。

## 本地运行

1. 在仓库根目录运行 `npm ci`、`npm run mini:build`、`npm start`。保持服务运行，默认地址 `http://127.0.0.1:8095`。
2. 微信开发者工具导入本文件所在目录 `wechat-miniprogram`。工程已配置游客 AppID，无需填写模型密钥。
3. 点击编译。总览默认连接本机服务端；下拉或点击更新获取香港天文台真实观测，停留总览时每3分钟自动更新。
4. 设置页检查连接，可改地区和服务地址。`urlCheck:false` 只用于本地调试。

Windows 可在 PowerShell 运行 `启动小程序.ps1`，自动打开本地工具；脚本会复用已启动的 RainGuard 服务端。

## 数据与功能

- 8 个官方来源沿用网页版接口，总览加载7种、助手按需获取详细警告；雨量站/18区/潮位可检索。
- 最新来源失败时回退到 **2026-10-12 的真实官方快照**，标出“历史快照”，保留观测时间和错误。缺失数据不补零；旧预报不用于当前安排。
- 离线包含22份官方知识资料及259段索引，保留原文链接和存档时间。网格快照仅裁剪18区最近网格，SHA256指向裁剪前官方原文件。数据再生成脚本复用网页版冻结数据，不额外造样本。
- 助手默认进行确定性来源核验，不调用模型。启用 Agent 后使用服务端 DeepSeek 工具调用及任务轮询；密钥只配置在仓库根目录的 `.env.local`。未配置时明确报错，不假冒AI回答。
- 人工创建实际设施、现场记录及复核任务，可添加JPEG/PNG照片（700KB以下）；完成须填写负责人、备注及三项核验。AI草稿只载入表单，人工保存后才成为任务。
- 本机记录保存在微信小程序存储。导出 JSON 可备份/分享；共享服务需配置 `WORKSPACE_TOKEN`。口令只在运行内存中保存，重启后重新输入。共享载入会替换本机记录，先导出；系统也保存上一版本于本机 `rg-document-backup`。
- 共享提交使用版本号，另一组员先提交时会拒绝覆盖。共享必须先载入，再编辑提交；不要把含照片的现场记录公开上传到 Git。

## 真机与正式发布

游客 AppID 仅用于本地工程运行；本次未进行微信平台上传或发布。真机预览需你的小程序 AppID。

手机无法使用电脑的 `127.0.0.1`。在相同Wi-Fi下将服务端以 `HOST=0.0.0.0` 启动，在小程序设置填写电脑实际局域网地址；开发阶段按工具要求设置网络校验和防火墙。正式运行请部署 Node 服务端到 HTTPS 域名，在小程序后台添加 `request` 合法域名，再将 `urlCheck` 改为 `true`。现有静态 Sites 页面不能承载这里的 Node 异步助手任务。

正式发布前配置 AppID、服务域名与隐私说明。照片保存在本机，只有人工提交共享工作台才发送到服务端。模型对话向服务器和模型供应商发送问题及证据上下文，避免输入个人敏感信息。

## 验证

`npm run mini:test` 检查快照降级、官方知识检索、完成校验与助手任务队列；`npm run mini:check` 连接已开启自动化的本地微信开发者工具进行模拟器验收。具体结果见 `验收记录.md`。工具自动化端口可设置为 `MINI_AUTO_PORT`，默认9435；HTTP端口和自动化端口是两回事。
