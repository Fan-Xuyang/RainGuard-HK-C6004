# RainGuard HK v0.3.0

## 实际数据扩展

核心冻结包保持原版本：671,724 条气象日记录、25 站日雨量及三站模型实验数据。新增独立扩展包包含 **1,199,668 条**官方气象日记录、**135 个**站点变量系列、**36 个**额外气象站，覆盖日最高/最低/平均气温、平均湿度和平均气压。合计 **1,871,392 条**记录，未用重复核心系列扩大计数。

原始 CSV、来源 URL、SHA-256、缺测/完整性字段、覆盖清单、SQLite 和正文快照全部保留。历史日系列本次仍更新到 2026-08-31，没有虚构9–10月观测。模型测试集未改变；扩展温湿压尚未用于新的多变量模型训练。

扩展包包含首次源发现中的404或正文不可提取记录，用于说明失败与排除。只有成功提取的资料计入知识库；失败页面没有作为知识依据。

## 知识与 Agent

网站接入 **22份官方资料、259个片段**。新增山泥倾泻、寒冷/酷热、季候风、热带气旋服务/分类/部门安排、信号参考指标和劳工处预防工作时中暑指引等。三个 PDF 保留物理页引用。检索采用词频、文长归一化及单文档最多两个证据位。

DeepSeek Agent 使用官方 [Tool Calls 协议](https://api-docs.deepseek.com/guides/tool_calls/)，由模型返回工具参数，服务端执行实际工具，再把结果交回模型继续分析。当前提供：

| 工具 | 实际能力 |
|---|---|
| search_knowledge | 检索官方正文并追加有效引用编号 |
| compare_regions | 比较最多五区的雨量，返回出处、观测时间、时效 |
| historical_events | 读取真实三站历史高雨量日，最多10项 |
| model_results | 读取既有五方法实测回测结果 |
| weather_window | 核验未来完整30/60分钟窗口；快照、过期或警告阻止当前建议 |
| draft_review | 生成未提交的人工复核草稿，不写数据库、不发停工指令 |

每次最多8个工具调用、4个模型轮次，保留参数、耗时、结果和失败轨迹。工具参数使用白名单，不能执行命令或访问用户给定任意URL。回答检查引用编号及来源时效，但没有把这种检查说成事实准确率或人工金标准评价。

“仅核验来源”不需要模型密钥，执行固定的官方知识、地区观测和窗口核验流程，并明确标为**未调用语言模型**。输入提及明确地区时优先核对该地区；没有地区时使用页面所选区域。它与模型自主选工具的 Agent 模式不同，不能据此声称已经验证大模型推理能力。

生成的草稿可以载入人工复核表单，用户填写负责人并明确保存后才成为本机工单；共享上传仍需要用户操作。私人对话、自导入资料、共享数据库中的设施附件不会自动发给模型。

## 新页面与界面

共12个页面。新增“数据工作台”：数据规模、站点变量覆盖搜索、质量标记及历史温湿压逐日图。逐日查询需要Node服务与已下载扩展SQLite；没有包时显示明确提示。手机布局使用两列指标/查询控件，宽表在容器内滚动；图表缺测不连线。

统一深蓝/青色视觉、卡片层级、表格悬停及焦点状态。知识证据过长时折叠，Agent轨迹与草稿优先显示，并使用中文工具名称。所有观测仍区分快照、在线、延迟和缺失。

## 获取与运行

```bash
npm ci
python scripts/download_dataset.py
python scripts/download_dataset.py --extended
npm start
```

已下载的数据包不会覆盖，请保留本机变更。下载先校验SHA-256，再安全解压。浏览器打开 http://localhost:8095；核心功能与“仅核验来源”不需要模型Key。模型Agent需在 `.env.local` 配置自己的DeepSeek Key。共享记录的口令与模型Key独立。

```bash
python -m pip install -r requirements.txt
npm run knowledge:sync
npm run experiment
npm test
npm run build
```

重新发现/采集额外资源使用 `npm run data:expand`。失败记录明确保存；核心包和既有模型不会因此自动改变。数据使用遵循各官方来源条款，新增资源原文不被重新授权为MIT。

## 验证与边界

实际执行了官方扩展采集、原文SHA核验、SQLite唯一键及完整性检查。Agent测试使用真实官方本地资料、模拟模型Tool Calls，覆盖多轮调用、非法参数、草稿不提交、快照阻止当前建议及执行预算。**本轮没有消耗真实DeepSeek额度做模型工具调用测试，也未完成人工问答评分。**

Chromium桌面及390px手机验证实际历史数据查询、无需密钥的工具核验、12页导航、JavaScript错误和页面横向溢出；已有共享权限/冲突/持久化检查保留。`npm run test:browser` 需要可用Chromium，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安装浏览器。

本轮交付并更新GitHub源代码与Release；原Sites演示不随推送自动升级。SQLite共享和扩展历史API仅适用于Node服务；Worker构建保留页面、天气和Agent但尚未把两套SQLite迁移到D1。未创建公开共享生产服务、未提供真实水浸概率或现场安全保证。
