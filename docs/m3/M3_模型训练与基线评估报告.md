# M3 模型训练与基线评估报告

## 1. 工作范围与主要结论

M3 负责三站降雨分类模型的训练、基线比较和结果解释。本次工作以项目已有实验为基础，先复现原实验，再补充简单基线、阈值审计、逐年分析及 2026 年保留集评估。

复现结果表明：原项目的 30 组“站点 × Trace 策略 × 方法”实验均可重跑；所有阈值和混淆矩阵与仓库原结果一致，指标最大绝对差约为 `1.39e-17`。新增分析使用 M1 指定的 Trace 排除数据，结果显示：

- 2023—2025 年测试集上，逻辑回归在三个站的平均精确率 AP 分别为 0.362、0.194 和 0.326，均高于对应月度发生率基线；但按 F1 评价，HKO 的持续性基线高于两个学习模型。
- 原发生率基线的候选阈值从 0.1 开始，使 LFS 和 SHA 的该基线只能全部预测为阴性。补充更低阈值后，两站的 F1 分别由 0 变为 0.093 和 0.152；其 AP 和 Brier 分数不变。
- 使用已固定的模型与阈值评估 2026 年保留集。该数据仅覆盖 1—8 月，且各站可用样本不同，因此结果只能作为一次有限的历史时间外检验。

上述结果对应项目自定义的“次日站点日总雨量是否达到 25 mm”二分类，不是官方暴雨警告、物业水浸概率或实时安全结论。

## 3. 输入特征、模型与评价方法

每个样本使用七个历史或日历特征：前 1、2、3 日雨量的 `log1p`、此前 7 日总雨量的 `log1p`、此前 7 日雨量不少于 1 mm 的天数，以及目标日期在年内位置的正弦和余弦。特征截止于目标日前一天。

| 方法 | 训练或计算方式 |
|---|---|
| 训练期总体发生率 | 对每个站点的所有日期输出该站训练期的正样本比例。 |
| 月度发生率 | 按目标月份输出训练期同月的正样本比例。 |
| 持续性基线 | 前一日雨量达到 25 mm 时输出 1，否则输出 0；阈值固定为 0.5。 |
| 逻辑回归 | 标准化仅在训练集拟合；`C=1`、`max_iter=2000`、`random_state=42`。 |
| 随机森林 | 120 棵树，最大深度 8，叶节点最少 10 个样本，随机种子 42。 |
| 新增前日状态概率基线 | 分别计算训练期“前一日达到 25 mm”和“未达到 25 mm”两组的次日正样本比例。 |

除持续性基线固定阈值外，原实验从 `0.1、0.15、0.2、0.25、0.3、0.4、0.5` 中选取验证集 F1 最高的阈值；并列时取列表中靠前的值。新增前日状态概率基线沿用同一规则。为审计阈值范围，另将 0 加入总体发生率基线的候选阈值，作为单独对照。测试集和 2026 年保留集没有用于选阈值或重新训练模型。

评价同时关注：AP（平均精确率，基于 `average_precision_score`）、ROC-AUC、Brier 分数、精确率、召回率、F1 和混淆矩阵。AP 主要评价概率排序，并受正样本比例影响；Brier 分数衡量概率预测的均方误差，越小越好。精确率、召回率和 F1 依赖分类阈值，不能仅凭其中一项判断方法优劣。

## 4. 原实验复现与测试集比较

下表为 Trace 排除策略下 2023—2025 年测试结果，单元格为“AP / F1”。前五种方法沿用原项目协议；后两种是本次补充的基线审计。

| 方法 | HKO AP / F1 | LFS AP / F1 | SHA AP / F1 |
|---|---:|---:|---:|
| 总体发生率：原阈值范围 | 0.149 / 0.259 | 0.049 / 0.000 | 0.082 / 0.000 |
| 月度发生率 | 0.220 / 0.323 | 0.104 / 0.170 | 0.178 / 0.268 |
| 持续性基线 | 0.263 / 0.421 | 0.105 / 0.263 | 0.172 / 0.344 |
| 逻辑回归 | 0.362 / 0.381 | 0.194 / 0.274 | 0.326 / 0.359 |
| 随机森林 | 0.349 / 0.408 | 0.158 / 0.216 | 0.322 / 0.378 |
| 前日状态概率基线（新增） | 0.263 / 0.421 | 0.105 / 0.263 | 0.172 / 0.344 |
| 总体发生率：加入 0 阈值（新增） | 0.149 / 0.259 | 0.049 / 0.093 | 0.082 / 0.152 |

逻辑回归在三个站的测试集 AP 都高于月度发生率，但随机森林并未在所有站或所有指标上优于逻辑回归。HKO 的持续性基线 F1 为 0.421，高于逻辑回归的 0.381 和随机森林的 0.408；不能笼统地说学习模型在每个指标上都优于简单基线。

两个学习模型的具体误报和漏报如下。TN、FP、FN、TP 依次表示正确阴性、误报、漏报和正确阳性。

| 站点 | 模型 | 阈值 | 精确率 | 召回率 | TN / FP / FN / TP |
|---|---|---:|---:|---:|---:|
| HKO | 逻辑回归 | 0.20 | 0.280 | 0.596 | 197 / 72 / 19 / 28 |
| HKO | 随机森林 | 0.20 | 0.300 | 0.638 | 199 / 70 / 17 / 30 |
| LFS | 逻辑回归 | 0.20 | 0.239 | 0.320 | 920 / 51 / 34 / 16 |
| LFS | 随机森林 | 0.15 | 0.146 | 0.420 | 848 / 123 / 29 / 21 |
| SHA | 逻辑回归 | 0.25 | 0.307 | 0.433 | 918 / 88 / 51 / 39 |
| SHA | 随机森林 | 0.20 | 0.290 | 0.544 | 886 / 120 / 41 / 49 |

例如，LFS 随机森林比逻辑回归多识别 5 个正样本，同时多产生 72 个误报。这里的阈值按验证集 F1 确定，不等同于考虑实际处置成本后的最佳阈值。

## 5. 新增基线与阈值审计

### 5.1 前日状态概率基线

该基线只看前一天是否达到 25 mm，并用训练期对应组的次日发生率作为概率；两组没有使用验证集或测试集计算。以 LFS 为例，前一日未达到 25 mm 的 6,439 个训练样本中，次日达到阈值的比例为 0.047；前一日达到 25 mm 的 390 个训练样本中，该比例为 0.218。

| 站点 | 前一日未达阈值：训练样本数 / 次日发生率 | 前一日达到阈值：训练样本数 / 次日发生率 | 原持续性 Brier | 新概率基线 Brier |
|---|---:|---:|---:|---:|
| HKO | 1,383 / 0.089 | 218 / 0.390 | 0.174 | 0.114 |
| LFS | 6,439 / 0.047 | 390 / 0.218 | 0.071 | 0.044 |
| SHA | 6,262 / 0.057 | 559 / 0.363 | 0.108 | 0.069 |

在本次各站数据及所选阈值下，新基线与持续性基线的分类结果和 AP 相同：两者都只按前一日状态将样本分成两组，且概率顺序相同。新基线避免直接把 0 和 1 当作确定概率，测试集 Brier 更低；这本身不证明概率已经充分校准。

### 5.2 总体发生率基线的阈值范围

LFS 和 SHA 的训练期总体发生率都低于 0.1，而原阈值候选的最小值是 0.1。因此原设置无论选择哪个候选值，两个站的该基线都预测全部为阴性，测试集 F1 为 0。把 0 加入候选后，验证集选择全阳性分类：LFS 测试集 F1 为 0.093，SHA 为 0.152，两个站的召回率均为 1，但精确率仅分别为 0.049 和 0.082。

这项补充用于展示阈值候选对分类评价的影响，并不改变预测概率、AP 或 Brier 分数。原项目结果仍按其原阈值范围保留，不能把两种设置混为一谈。

## 6. 新增逐年表现与区间估计

| 站点 | 测试年份 | 测试样本数（正样本） | 逻辑回归 AP | 随机森林 AP |

| HKO | 2024 | 98（12） | 0.316 | 0.283 |
| HKO | 2025 | 124（19） | 0.355 | 0.311 |
| LFS | 2023 | 336（15） | 0.194 | 0.170 |

HKO 每年的有效样本和正样本较少，逐年 AP 波动明显；不能把某一年的高值当作稳定水平。测试集 1,096 个自然日中，HKO 只有 316 个有效目标日，LFS 有 1,021 个，SHA 有 1,096 个。Trace 排除和完整性过滤可能造成样本选择偏差，各站指标也不宜直接当作同一批日期上的比较。

为补充测试期结果的不确定性，本次将同一年、同一月的样本作为一个块，在相同日历月份内对年份月份块进行 1,500 次有放回的配对重采样，报告 AP 差的百分位 95% 区间（随机种子 20261106）。模型与阈值在重采样时不重新训练；HKO 使用 34 个有样本的月份块，LFS 和 SHA 各使用 36 个。

| 站点 | 逻辑回归 AP − 月度基线 AP：差值［95% 区间］ | 随机森林 AP − 逻辑回归 AP：差值［95% 区间］ |
|---|---:|---:|
| HKO | 0.142［0.075，0.231］ | -0.013［-0.090，0.040］ |
| LFS | 0.090［0.068，0.119］ | -0.036［-0.056，-0.008］ |
| SHA | 0.148［0.106，0.184］ | -0.005［-0.028，0.018］ |

区间只反映固定已训练模型在当前测试样本上的块重采样变动，不涵盖重新训练、特征选择、数据筛选及跨年份分布变化带来的全部不确定性。年份和月份块数量有限；这些是探索性结果，不视为独立外部验证或现场效果证明。

## 9. 限制与交接

1. 本次标签是项目自定义日雨量分类，不代表官方暴雨警告、真实积水或损失；不能把模型输出当作物业水浸概率。
2. 日雨量历史数据有发布滞后，2026 年数据又不完整，当前模型结果用于有日期的历史回放，不能声称已实现当天的实时次日预测。
3. Trace 排除会影响目标日及此前七日窗口，尤其显著减少 HKO 样本；对全体日期、其他站点或其他 Trace 处理策略的推广需要另行检验。
4. 月份块重采样和 2026 年评估均为有限的探索性检查；原测试集结果已公开，2026 年保留集也已被本次使用。
5. M2 可使用同一冻结数据继续开展特征与 Trace 敏感性分析；M4／M5 接入页面时应标明历史日期和模型边界；M6 汇报时应同时展示误报、漏报及各站样本规模。
