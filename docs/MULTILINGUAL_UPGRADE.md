# 三语与知识工作台使用说明

更新日期：2026-10-15。完整入口：http://127.0.0.1:8100/ 。

## 切换语言

右上角提供简体中文、粵語、English。粤语使用繁体字及香港粤语表达，语言偏好保存在浏览器本地；进入同一8100地址的企业控制台也会沿用。不同浏览器或端口的本地存储彼此独立。

菜单、动态标签、表单提示随选择更新，地区字段实际值保持官方编码/名称。官方原文引用、聊天历史、用户输入与已有工作流分析保留原样。新发送的助手问题会携带所选语言；新建企业流程把语言偏好写入持久化状态。不会为切换语言重新调用付费模型或改写旧审计记录。

## 使用知识工作台

进入「官方知识库」，可按主题、发布部门、原文语言筛选，也可输入中文、粤语或英文关键词。显式同义词表覆盖暴雨、水浸、台风、雷暴、酷热、风暴潮、山泥倾泻、恶劣天气工作安排等主题，再以词频和文档长度归一化排序。同一来源最多占两个证据位置。

点击「收藏资料」后，可勾选「仅看收藏」。收藏只存本机。点击「带入助手核对」将来源标题和链接填入助手输入框，仍需自行点击发送；不会自动产生模型费用。导出的JSON引用清单包含筛选条件、URL、抓取时间、校验值和片段数量，不伪造引用或加入模型生成原文。

当前共有 **44份官方资料、370个检索片段**，其中22份新增英文原文。来自香港天文台、渠务署、劳工处。新增抓取清单及失败项见 [knowledge-manifest.json](../hk-web/data/knowledge-manifest.json)。两条紫外线候选URL本次返回错误，未计入新增资料；没有用生成内容补齐。

每条资料保留抓取时间、真实源URL及原始文件SHA-256；PDF沿用物理页号。抓取时间不等于政策生效时间，也不表示原文内容已通过人工政策审查。天气实时接口、长期气候数据和一般知识文档保持各自来源与时效标记。

## 场景核对手册

「作业与现场」上方新增6套模板：物业排水巡查、户外作业交接、沿岸设施值守、高温作业复核、斜坡周边巡查、台风前后交班。

选择模板后可逐项勾选、查看官方原文、建立人工复核草稿或导出核对包。勾选进度只保留在本次页面；导出包包含勾选状态、真实来源元数据和本次观测来源状态。模板是项目整理的人工核对提纲，不是政府发布的完整作业规程，不会自动判断现场安全或批准停工/复工。

## Agent与其他工具

Agent现有8个允许工具：官方知识检索、地区比较、历史高雨量检索、固定离线模型结果、作业降雨窗口核验、人工复核草稿、知识库覆盖查询、来源时效与缺测检查。新增两个工具分别名为 `knowledge_inventory`、`observation_health`。数据健康检查即使返回成功，也不推导现场安全结论；快照仍明确标记快照和时效。

页面右上角「快速查找」或Ctrl/Cmd+K可查找功能和官方资料。「数据工作台」查询真实气候系列后可导出CSV，保留缺测、完整性与原始来源字段。本机数据库通过只读挂载读取；未安装扩展数据的其他电脑会明确提示缺少数据。

小程序知识包同步到44份资料并沿用同义词检索；本次三语界面覆盖网页版工作台及企业网页，小程序界面暂未三语化。

## 维护与验证

```powershell
# 更新官方中英资料，失败项目会写入清单；实际网络请求可能耗时
python scripts/extend_knowledge.py

# 验证逻辑及构建
npm test
npm run build
npm run mini:build
python -m pytest enterprise/tests -q

# 启动或更新本机部署
docker compose --env-file runtime/enterprise.env -f compose.enterprise.yml up -d --build --wait

# 浏览器验证：使用本机已有Chromium；路径可用环境变量覆盖
node scripts/language_browser_check.mjs
node scripts/unified_browser_check.mjs
```

UI语言词典已随源码提交，正常使用无需调用翻译服务。`locale-overrides.json` 保存人工校订的核心措辞。可选的 `build_locale_catalog.py --use-local-model` 读取本机DeepSeek配置，为新收集的产品UI短语生成翻译，会产生模型费用；它不发送业务记录或官方原文正文，只处理界面文案及标题。新增翻译需要检查占位符、否定含义和术语，再运行浏览器验证。禁止将密钥和runtime目录提交到仓库。

本次已验证14项Python测试、现有Node测试及新增语言/工具测试；真实浏览器覆盖三语往返、原有12页、语言偏好保留、表单原值、知识筛选/收藏/导出、场景草稿、快速查找及390px手机布局。企业三角色审批、现场核验、复审归档在隔离测试库通过，正式业务库未写入测试流程。新增语言策略通过请求协议与队列/检查点测试；未额外调用付费模型验证每一种业务回答的翻译质量。UI词典生成使用了受限的真实翻译请求。
