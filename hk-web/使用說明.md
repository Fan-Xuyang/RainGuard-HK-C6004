# RainGuard HK 香港天氣營運工作台

## 使用場景與真實資料

服務於香港物業、沿海設施和戶外作業的天氣值守研究：查看區域雨量、參考潮位和官方預報；核對官方警告；為實際管理的設施登記關注規則；記錄人工核查與圖片證據。本原型未與任何真實機構建立派單或巡檢服務關係。

資料由香港天文台提供，來源為 DATA.GOV.HK 公布的官方接口。8 組資料涵蓋氣象站一小時雨量、地區天氣、實測潮位、兩小時網格降雨預報、九天天氣、本地預報、警告摘要與詳情。另附天文台、流浮山、沙田 2000 年起的日雨量記錄。

## 啟動

安裝 Node.js 22 或更新版本，解壓後在專案目錄開啟 PowerShell：

```powershell
node serve-hk.mjs
```

瀏覽器開啟 http://localhost:8095 。Ctrl+C 停止。請使用這個啟動方式，Python 靜態服務沒有 /api 後端，不能完整更新潮位與網格預報。不要雙擊 HTML。

線上版本沿用交付連結，保持既有私有訪問範圍。

## 功能與演示流程

1. **營運總覽**：先顯示已下載的真實快照，隨後嘗試官方在線更新。查看四個指標、香港互動地圖、參考潮位及兩小時預報。
2. **切換區域**：在地圖點選或下拉選擇香港 18 區，查看區域一小時雨量和最近官方預報網格。地圖標點是區域參考位置，不是官方感測器座標。
3. **站點檢索**：在雨量與潮位頁切換 36 個雨量站、18 區雨量與 7 個潮汐站，搜尋、排序、收藏及匯出目前列表 CSV。缺測保留為「—」。
4. **預報與警告**：查看四段半小時官方預報、九天天氣和生效警告。無警告時如實顯示，資料延遲時提示。
5. **歷史與模型**：選擇三個歷史站點與年份，查看日雨量圖、高雨量日期、完整性標記與模型測試結果；匯出年度 CSV 或模型參數。
6. **設施登記**：填寫你實際管理或研究的設施名稱、區域、參考潮位站與關注事項。設施清單初始為空，不預置虛構客戶。
7. **關注規則**：設定一小時雨量與參考潮位關注值。點選「檢查關注規則」，只以新鮮在線資料產生人工核對建議；快照、缺測或延遲資料不自動觸發。多項關注代表優先人工核對，不是淹水概率。
8. **復核工單**：手動建立或由設施建立工單，系統保留當時雨量、時間、來源、潮位、警告和規則。填寫實際負責人、核查結論，完成三項確認後標記完成。
9. **圖片證據**：可上傳自己取得的 PNG/JPEG，每張小於 700 KB。圖片是使用者證據，不是系統或政府確認的現場事實。
10. **資料中心**：查看每個接口的官方 URL、資料時間、接收時間、SHA256、下載原始快照或匯出本頁資料。
11. **備份與報告**：匯出 JSON 證據、備份／還原工作空間；右上角列印按鈕可使用瀏覽器「另存為 PDF」。還原會替換當前本機工作空間，請先備份。

## 更新與資料狀態

預設在線模式，頁面開啟期間每 5 分鐘更新；可取消自動更新或切換真實快照。服務端使用固定官方來源白名單、最長 3 分鐘快取與逾時控制，解決潮位和網格 CSV 的跨域限制。頁面關閉後不會持續輪詢。

每個來源獨立顯示在線、快照、延遲或更新失敗狀態。接口失敗保留先前真實資料，明確標記更新失敗；不以合成值替代。來源中心的延遲門檻是本項目顯示規則，不是官方服務承諾。警告 API 空物件僅表示該次查詢未返回生效警告；歷史快照不能代表當前狀態。

雨量為滾動一小時累計，不能把每 15 分鐘的數值直接相加。潮位採用海圖基準 mCD，不是河道水位。網格半小時預報為面積平均值，不能與單點雨量觀測當作同一測量。每個時間均以香港時間 HKT 顯示。

## 歷史資料與模型實驗

歷史來源：https://data.gov.hk/en-data/dataset/hk-hko-rss-daily-total-rainfall

本次下載每站 9,740 條日記錄，三站合共 29,220 條，包含 Trace 微量、*** 缺測及 # 不完整標記。實際最後日期和數量以 history.json 為準。圖表保留原始標記；合計僅包含完整數值日，不將部分日合計標成完整年總量。

分類目標：站點次日總雨量是否 ≥25 mm，屬課程自訂標籤，非官方暴雨或水浸標籤。模型為標準化特徵後的邏輯回歸：前 1–3 日雨量、前 7 日累計／濕日數和年內季節項。僅使用目標日前已可取得的觀測。

- 訓練：2000–2019。
- 驗證：2020–2022，以 F1 選定分類閾值。
- 獨立測試：2023–2025，保留 Precision、Recall、ROC AUC、PR AUC、Brier、混淆矩陣和逐日測試結果。
- 基線：僅由訓練期計算的月份正例頻率。
- 缺測、Trace 及不完整日不填值；不滿足連續 8 日完整數值的窗口排除。天文台站因 Trace 較多，可用樣本較少，需報告此選樣限制。

此模型僅離線回測；歷史氣候檔按月更新，與臨時自動站來源不同，沒有將其接成即時次日預警。未訓練香港河道預測或設施水浸模型。

## 重新下載、訓練與檢查

```powershell
python download_hk.py
python -m pip install numpy scikit-learn
python train_hk.py
node build-hk.mjs
node test-hk.mjs
node serve-hk.mjs
```

download_hk.py 保留官方響應原始位元組與 SHA256；hk-web/data/raw 為原始檔。snapshot.json 為整理後快照，模型係數與逐日測試結果位於 models.json。重新下載後需重新 build；部署則需重新發布。

## 保存方式與限制

收藏、設施、規則、工單和圖片存在當前瀏覽器 localStorage。不是多人共享資料庫，沒有登入角色、真實派單或外部通知。清除瀏覽器儲存會遺失記錄，使用備份匯出保留。讀取官方資料由服務端執行，使用者復核內容不會傳往政府接口。

OpenStreetMap 底圖與網路字型需要網路；失敗時列表、系統字型及快照仍可使用。瀏覽器畫面視覺驗證若未完成，請以交付說明為準。
